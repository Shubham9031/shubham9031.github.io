# Developer Portfolio (Shubham Ojha Portfolio Clone)

A modern, high-performance, dark/cyberpunk themed portfolio featuring 3D Three.js animations, GSAP scroll triggers, glassmorphism UI, interactive physics hanging portrait, and responsive layouts.

---

## 🌟 What is in this Portfolio? (Full Breakdown)

### 1. **Visual Theme & Design System**
- **Theme**: Dark obsidian background (`#07070a`) with vivid crimson/red neon accents (`#a31515`, `#ff2a3b`).
- **Typography**: Clean modern typography powered by [General Sans](https://api.fontshare.com/v2/css?f[]=general-sans).
- **Effects**:
  - **Glitch Intro Preloader**: Numeric 0–100% counter with curtain reveal animation.
  - **Spark Cursor**: Interactive HTML5 Canvas particle sparks & electric arcs following cursor movement.
  - **3D Hero Mosaic**: Interactive Three.js glass shard mosaic with red iridescence and 3D depth.
  - **3D Starry Background**: Ambient dust/particle field drifting continuously.
  - **Interactive Hanging Portrait**: Physics-based swinging picture frame with mouse interaction.

## 🚀 How to Run the Portfolio Locally

### Step 1: Start the server
```bash
npm start
# or
node server.js
```

### Step 2: Open in your browser
Go to: [http://localhost:3000](http://localhost:3000)

---

## ✏️ How to Customize with Your Information

### 1. Update Profile Photo
Replace `/media/profile.webp` or `/public/media/profile.webp` with your own photo.

### 2. Update Details Using `customize.py`
Edit `customize.py` with your name, email, phone, and links, then run:
```bash
python3 customize.py
```
